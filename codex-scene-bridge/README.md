# Wallpaper Engine 场景桥接组件

现有皮肤管理器负责扫描与导入 Wallpaper Engine 视频壁纸。本项目增加的通用组件补齐了 **Scene 场景壁纸**的运行入口，让视频和场景都能进入相同的「导入到主页 → 应用到 Codex」流程。

## 增加的支持

- 使用已安装并运行的 Wallpaper Engine 原生渲染场景，输出到组件自己的离屏窗口。
- 只捕获经过路径与窗口身份核对的场景窗口，将画面实时传给 Codex 背景层，无需逐张录成 MP4。
- 通过组件自己的本地传输适配皮肤页面，退出后清理对应的播放器、流和传输入口。
- 自动生成场景预览图，供开场动画跟随同一张壁纸；开场使用预览图制作动画，进入应用后播放实时场景。
- 预览从真实渲染的多帧中选取，保存尺寸和校验摘要；不把 Workshop 缩略图当成完整场景。抓帧在后台运行，失败重试时保留已有可用画面。
- 新启动会话自动恢复场景流；界面验证与预览采集分开进行，短暂连接失败不会立即中断应用。
- 扫描时识别部分使用 `gifscene.pkg` 等非标准名称的场景，在经过路径和包头验证后创建同目录硬链接别名，不复制整份素材、不覆盖已有 `scene.pkg`。

## 使用

按根目录 [安装说明](../README.md#安装) 安装后，组件位于管理器旁的 `scene-runtime`，由管理器自动发现。

保持 Wallpaper Engine 和皮肤管理器运行，打开管理器的 **Wallpaper Engine** 列表，选择本地已下载的视频或场景，点击 **导入到主页**，再从主页 **应用到 Codex**。新下载的场景会在再次打开列表时扫描识别，不需要逐张安装组件；导入和切换仍由使用者决定。

## 范围

默认场景输出 1280×720、15 FPS。鼠标事件不转发给场景，编码流不含音轨；引擎本身的声音由 Wallpaper Engine 设置管理。这里只说明 Video 和 Scene，未增加 Web 壁纸或应用类壁纸支持。

曾在原安装环境验证 25 张场景的渲染和流解码，并验证一张场景在实际 Codex 中的视频帧推进、主题还原和退出清理。驱动、场景依赖和应用升级仍可能影响兼容性，不能解释为所有未来场景均已验证。
